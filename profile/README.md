# Doors YU Club

We are a student club building and learning through technology projects. This GitHub organization is the shared home for our code and project work.

New contributors can start with our [contribution guide](https://github.com/Doors-YU-Club/.github/blob/main/CONTRIBUTING.md). Each project repository explains its own goals, setup, and maintainers.

Please do not put credentials, private university information, or personal data into public issues or repositories.
