# Doors YU Club GitHub standards

This public repository holds the shared contribution guidance for Doors YU Club projects. GitHub displays supported files here as defaults when a project repository does not provide its own version.

- [Contributing](CONTRIBUTING.md): how members propose and review work.
- [Security](SECURITY.md): how to raise a potential vulnerability.
- [Code of conduct](CODE_OF_CONDUCT.md): how we work together.
- [Issue templates](.github/ISSUE_TEMPLATE): how to request or report work.

Project-specific setup, tests, owners, and AI instructions belong in each project repository. The club's [project template](https://github.com/Doors-YU-Club/doors-project-template) provides a starting point.

These documents can be improved through pull requests as the club learns what works.
