# Security reporting

If you find a potential security issue, do not post exploit steps, credentials, or private data in a public issue or pull request.

For a public repository with **Report a vulnerability** enabled, use that private GitHub reporting form. Otherwise, contact club leadership through the club's official channel and ask to be connected with the project's tech maintainer. Share sensitive details only after a private channel is agreed.

Maintainers should acknowledge a report, assess the impact, coordinate a fix, and avoid public disclosure until affected people can be protected. Project repositories may provide a more specific reporting path.
